Reflective Analysis: 
I created this map to help users find places where they can buy food, without the noise of typical mapping services. I often feel overwhelmed when using Google Maps to find food near me, because it offers so much information at once. I also worry about how it is preferencing what information it shows me, based on algorithm marketing or biased sources. Using Vancouver Open Data portal, I gathered storefronts from as recent as 2026, ensuring the shops are still open and legally registered whereas google maps allows users to add their own storefronts. My map doesn’t prefer storefronts by their marketing or reviews, as google maps does. My map uses simple and refined data to allow a user to see all the sources of food near them within the points of a radius they select, anywhere in Vancouver. 
I chose to filter by name of storefront (business_name) because it is more informative than the type of storefront (general_business_name) which only has two options in the dataset: convenience or food. The filter by name allows users to enter specific store names or general description words and highlights locations across the city, represented in equal size and shape. I was unable to manually filter shops by their more specific purpose such as which type of cuisine they have or whether or not they are locally owned, because this data was not publicly available on Vancouver Open Data Portal. However, typing cuisine names like “sushi” will still yield many results because the cuisine is often in the actual storefront name. If I were to do this project again with more time I would look for more information for storefronts, to provide the user with a more detailed description of the storefronts.
